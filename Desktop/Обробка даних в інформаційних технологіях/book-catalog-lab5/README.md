## 4. Хід роботи
Під час виконання лабораторної роботи було створено новий проєкт на базі Spring Boot. Організація коду відповідає патерну MVC:
* **Model (Модель):** Містить класи, що представляють сутності бази даних (`Book.java`)[cite: 189].
* **Repository (Репозиторій):** Створено інтерфейс `BookRepository` для взаємодії з PostgreSQL[cite: 181].
* **Controller (Контролер):** Містить Java-класи, які обробляють НТТР-запити (`BookController.java`)[cite: 191].
* **View (Представлення):** Містить HTML-шаблони, які формують інтерфейс користувача (`book-list.html`, `book-form.html`) у папці `templates`[cite: 186, 190].

Замість клієнтського рендерингу (Vue.js) було використано серверний шаблонізатор Thymeleaf для динамічної генерації HTML-сторінок [cite: 14-17]. [cite_start]Для стилізації інтерфейсу (кнопки, таблиці, форми) підключено CSS-фреймворк Bootstrap [cite: 24-26].
Також було реалізовано глобальний обробник помилок (`GlobalExceptionHandler.java`) та створено сторінку `error-page.html` для відображення у разі виникнення виняткових ситуацій [cite: 227-238].
