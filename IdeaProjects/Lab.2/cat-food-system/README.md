# Лабораторна робота №2: Інтеграція Front-end та Back-end

**Тема:** Створення веб-застосунку з використанням Java Servlets та Vue.js  
**Виконала:** Кичата Софія, студентка групи МІТ-21

## Опис проєкту
Проєкт являє собою веб-застосунок — каталог інтернет-магазину "Муркотик". Застосунок демонструє клієнт-серверну архітектуру, де фронт-енд отримує дані про товари (корм для котів) від бек-енду у форматі JSON та динамічно відображає їх на сторінці.

## Використані технології
* **Back-end:** Java 21, Jakarta EE (Servlets), Apache Maven
* **Front-end:** HTML, CSS, JavaScript, Vue.js 3, Vite
* **Сервер:** Apache Tomcat 10
* **Бібліотеки:** Gson (для серіалізації об'єктів у JSON)

##  Інструкція із запуску

1. Відкрийте термінал у папці `cat-food-system` та зберіть фронт-енд:
   `npm run build`
2. Скопіюйте вміст згенерованої папки `dist` у папку `src/main/webapp` Java-проєкту.
3. Зберіть бек-енд за допомогою Maven (команда `package`).
4. Скопіюйте згенерований файл `Lab_2_Project.war` з папки `target` у папку `webapps` вашого сервера Tomcat.
5. Запустіть сервер Tomcat (`startup.bat`).
6. Відкрийте браузер за адресою: `http://localhost:9090/Lab_2_Project/` (змініть порт на ваш, якщо він відрізняється).

##  Відповіді на запитання для самоперевірки

**1. Які функції виконує сервлет у проєкті?**
У цьому проєкті сервлет (`CatFoodServlet`) виконує роль Back-end контролера. Він приймає HTTP-запити (GET) від клієнта за певною адресою, створює список об'єктів товарів, перетворює ці об'єкти у формат JSON і відправляє їх назад у браузер як відповідь.

**2. Як відбувається обмін даними між фронт-ендом і бек-ендом?**
Обмін відбувається через HTTP-запити. Фронт-енд (Vue.js) за допомогою функції `fetch()` відправляє GET-запит на сервер. Бек-енд (Java-сервлет) отримує запит, формує дані та віддає їх у вигляді текстового рядка у форматі JSON. Фронт-енд отримує цей рядок, розпаковує його назад у масив і відображає на сторінці.

**3. Що таке JSON і чому він використовується для передачі даних?**
JSON (JavaScript Object Notation) — це легкий текстовий формат обміну даними. Він використовується, тому що є універсальним: він легко читається людьми і так само легко обробляється будь-якими мовами програмування.

**4. Як налаштувати Vue для інтеграції з Java-сервлетами?**
Для цього потрібно налаштувати проксі-сервер у файлі `vite.config.js`, щоб перенаправляти запити на Tomcat. Також після збірки Vue-проєкту (`npm run build`), згенеровані файли з папки `dist` переносяться у папку `src/main/webapp` Java-проєкту.

**5. Як працює бібліотека Gson для серіалізації об'єктів у JSON?**
Бібліотека Gson автоматично бере Java-об'єкт (або список об'єктів) і перетворює його поля на ключі та значення у форматі JSON за допомогою методу `gson.toJson()`.

**6. Які параметри можна задати для опису вашого об'єкта?**
Для опису об'єкта `CatFood` було задано 5 параметрів: `brand` (бренд), `flavor` (смак), `weightKg` (вага), `price` (ціна), `imageUrl` (посилання на фотографію).

**7. Як обробляти помилки при отриманні даних у Vue?**
У Vue помилки обробляються за допомогою конструкції `try...catch` під час виконання асинхронного запиту `fetch()`. Якщо сервер недоступний, код переходить у блок `catch`, де помилка виводиться в консоль.
